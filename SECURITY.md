# Política de seguridad

## Informar de una vulnerabilidad

No abras un issue público. Usa **[Report a vulnerability](../../security/advisories/new)** (pestaña *Security* del repositorio) para enviarla de forma privada.

Incluye, si puedes: versión o commit afectado, pasos para reproducirla y el impacto que ves. Responderé en un plazo de 7 días.

## Versiones soportadas

Solo se mantiene la rama `main`.
